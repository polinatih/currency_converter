# currency_converter

Десктопный конвертер валют с графическим интерфейсом (Tkinter) по официальному курсу
Национального банка Молдовы (BNM).

Проект выполнен по методологии Spec-Driven Development: спецификации подготовлены в
GitHub Spec Kit (`specs/001-currency-converter-ui/`), код собран агентом Google Antigravity
по файлу задач `tasks.md`.

## Возможности

- Конвертация между любыми валютами из ежедневного XML-курса BNM и молдавским леем (MDL)
  в обе стороны, включая кросс-курсы через MDL (например, USD → EUR).
- Учёт номинала BNM (`Nominal`): курс пересчитывается на одну единицу валюты.
- Отображение результата (2 знака), курса пары `1 USD = X MDL` (4 знака), даты курса и источника.
- Кнопка «Конвертировать» неактивна, пока сумма не введена корректно; причина ошибки
  показывается под полем ввода.
- Работа без сети и в выходные (см. «Поведение при отсутствии данных»).

## Требования

- Python 3.12 или новее (проверено на Python 3.14, Windows)
- Tkinter (входит в стандартную установку Python для Windows)
- Сторонние библиотеки не нужны — используется только стандартная библиотека

## Запуск

Из корня репозитория:

```powershell
py -m src.app
```

## Тесты

Все unit-тесты запускаются одной командой из корня репозитория:

```powershell
py -m unittest
```

| Файл | Что проверяет |
|---|---|
| `tests/test_rates.py` | разбор XML BNM, номинал, конвертация, формат вывода, таймаут, откат по датам, кэш |
| `tests/test_source_edge_cases.py` | битые и пустые ответы, HTML вместо XML, нулевые курсы, выходные, конвертация туда-обратно |
| `tests/test_validation.py` | валидация суммы: пусто, ноль, минус, буквы, `nan`/`inf`, одинаковые валюты |
| `tests/test_ui.py` | окно Tkinter; пропускается автоматически, если Tkinter или дисплей недоступны |

Сетевые запросы в тестах подменяются (mock), поэтому интернет для их запуска не нужен.

## Источник данных

Официальный XML-фид Национального банка Молдовы:

```
https://www.bnm.md/en/official_exchange_rates?get_xml=1&date=DD.MM.YYYY
```

Курс публикуется в рабочие дни (обычно до 13:00 по Кишинёву). Запрос выполняется через
`urllib` с таймаутом 10 секунд.

## Поведение при отсутствии данных

1. **Выходные и праздники.** Если на сегодняшнюю дату BNM вернул пустой ответ, приложение
   запрашивает предыдущие дни по одному, максимум на 10 дней назад, и использует первый
   найденный курс. Пользователь видит предупреждение с фактической датой курса.
2. **Нет сети или некорректный ответ.** Приложение не падает: оно автоматически берёт
   последний успешно полученный курс из локального кэша и показывает предупреждение
   с его датой и источником.
3. **Нет сети и нет кэша.** Показывается понятная ошибка, конвертация не выполняется.

## Кэш

Последний успешный ответ сохраняется в файл `rates_cache.json` в корне проекта
и переживает перезапуск приложения. Пустые, повреждённые и неудачные ответы кэш
не перезаписывают. Файл создаётся автоматически и исключён из git (`.gitignore`).
